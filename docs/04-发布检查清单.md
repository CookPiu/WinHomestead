# 发布检查清单 v1

日期：2026-09-03
适用：M4 及之后每次对外发布。自动化部分由 `build\publish.ps1` 完成，本文只列人工步骤与通过标准。

---

## 1. 自动化门槛

| 步骤 | 命令 | 通过标准 |
|---|---|---|
| Debug 构建 + 单测 | `.\build\build.ps1` | 0 警告 0 错误，测试全部通过 |
| Release 单 exe | `.\build\publish.ps1` | Costura 已织入（校验 `costura.*` 资源），`NewPcSetup.exe` < 10 MB |
| 签名 | `.\build\publish.ps1 -Thumbprint <sha1>` | `signtool verify /pa` 通过，时间戳为 RFC3161 SHA256 |

签名证书只放在发布机的证书库中，不进仓库；脚本不接受 pfx 路径与密码参数。

---

## 2. Hyper-V 验收矩阵

每个格子在**全新安装、未登录微软账户、已联网**的虚拟机上跑；执行前后各跑一次 `build\inspect-machine.ps1` 保存输出做对比。

| 镜像 | 单盘无分区 | 单盘已有 D | 双盘 |
|---|---|---|---|
| Win11 Home 24H2 | UC-05 自动分区 + 全流程 | 全流程 | 全流程 |
| Win11 Pro 25H2 | UC-05 自动分区 + 全流程 | 全流程 + UC-12 续跑 | 全流程 |

虚拟机建议配置：4 vCPU、8 GB、系统盘 512 GB 动态扩展（触发 512 GB 规则），双盘用例再挂一块 256 GB 空盘。

## 3. 每台机器的走查步骤

1. 双击 exe，只弹一次 UAC；非管理员账户下应提示后退出。
2. 头部只有探测状态、条目汇总、数据盘下拉与“重新探测”，不再堆机器摘要；探测 ≤ 15 s；探测期间所有“执行”按钮禁用。
3. “这台电脑”栏位（左栏第一项）：系统、机型、处理器、内存、每块盘、每个卷的总量/已用/剩余与本机实际一致；容量保留两位小数并附字节数，与任务管理器、磁盘管理对得上，不能出现把 31.43 GB 显示成 32 GB 这类取整。
4. 分类：单盘无分区时“分区”分类出现“压缩 C 盘并新建数据分区”（可选，执行前二次确认）与“分盘建议（手动）”；有数据盘时“磁盘与路径”“开发缓存”按检测结果列出。
5. 徽标：默认执行组标“推荐”，风格/输入法/去推送/系统 TEMP/关闭休眠标“可选”，已满足的无按钮并标“已满足”，不适用的显示原因。
6. 逐项执行：点一项 → 还原点（首次）→ Apply → Verify → 卡片下方显示结果 → 列表刷新为“已满足”。失败项显示“失败，已回滚”且注册表值恢复原值（用 inspect 输出对比）。配置文件类（Maven `settings.xml`、`.condarc`）执行后原文件旁应出现 `.newpcsetup-bak` 备份，回滚后内容还原；原本不存在的文件回滚后被删除。
7. 依赖：在没有目录骨架时直接执行“迁移下载”，应先自动执行“建立数据盘目录骨架”，两项都出现在结果里；执行期间进度行旁出现“停止”按钮，点了在当前项做完后停止，已完成项保留。
8. OneDrive：桌面被备份接管时，“迁移桌面”标不适用，头部提示条的“打开 OneDrive 设置”能唤起 OneDrive 设置窗口；在 OneDrive 里关掉桌面备份后点“重新探测”，该条变为可执行。
9. npm 全局包：`%APPDATA%\npm` 为空的机器上“npm 全局包目录迁移”可执行，执行后 `.npmrc` 的 prefix 指向数据盘且 registry 等其他行保留，用户 PATH 末尾多出该目录；`%APPDATA%\npm` 里已有全局包时该条标不适用。
10. 提示条：执行过“重启资源管理器生效”的项后出现“重启资源管理器”按钮，点后桌面刷新；执行过需重启项后出现“立即重启”。
11. 检查项页：六项都出结果，无一项显示"未知"（BitLocker 需管理员，非提权运行时才会未知）；OEM 预装只列出整机厂商发行的程序，不应出现 MSI Afterburner、`vs_*msi` 这类误报；每个跳转按钮都能打开对应设置页。软件推荐页底部"商店应用保存位置"能打开 设置 → 存储 → 高级存储设置。
12. 执行记录页：结果、手动项（OneDrive 桌面、Docker、Maven/Conda 若检测到）；“导出 HTML 报告”生成文件并打开。
13. 立即重启：RunOnce 写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce\NewPcSetup`，重启后工具自动打开并先显示复核后的记录，需重启项变为“完成”。
14. 再次运行：执行过的项全部为“已满足”，分类副标题显示剩余可执行数。
15. 软件推荐页：根目录默认 `<数据盘>\Applications`，每项路径形如 `…\Tools\7-Zip`（按分类分子目录）；改根目录后所有未自定义的项跟着变；单项改完标“自定义路径”，重进页面仍在；“恢复默认”清空全部；不支持自定义路径的项没有路径框。
16. 分区用例（仅单盘无分区）：执行后磁盘管理中 C 被压缩到建议值、新卷 D 为 NTFS 卷标 Data；C 盘文件完好；列表自动重新探测并出现路径类条目。
